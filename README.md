# StudyNotes

تطبيق ويب (MVP) يساعد الطلاب على إنشاء ملاحظات دراسية بصرية جاهزة (Sticky Note، Handwritten Note، Mind Map) بسرعة، عبر مسار: **تخصص ← قالب ← معلومات ← معاينة ← حفظ/تحميل**.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

للبناء للإنتاج:

```bash
npm run build
npm run preview
```

## بنية المشروع

```
src/
  components/       مكونات الواجهة العامة (Header, SpecialtyCard, TemplateCard,
                     NoteForm, NotePreview, SavedNotes, HowItWorks)
  data/
    specialties.js  قائمة التخصصات الستة
    templates.js    كل القوالب (مصنّفة حسب التخصص والنوع) + بيانات تجريبية عربية حقيقية
  templates/         التصميمات البصرية الثابتة الثلاثة
    StickyNote.jsx
    HandwrittenNote.jsx
    MindMap.jsx
  utils/
    storage.js      حفظ/قراءة/حذف الملاحظات عبر localStorage (طبقة معزولة لتسهيل
                     الانتقال إلى Firebase لاحقًا دون تغيير الواجهة)
    exportImage.js  تصدير القالب المعروض كصورة PNG عبر html2canvas
  App.jsx           إدارة التنقل بين الشاشات (الرئيسية / التخصص / مساحة العمل / ملاحظاتي)
  styles.css        كل الأنماط (RTL، Mobile First، هوية بنفسجية هادئة)
```

## الوظائف المنفذة

- اختيار تخصص من ستة تخصصات (طب، هندسة، فيزياء، كيمياء، رياضيات، إعلام آلي).
- لكل تخصص ثلاثة قوالب جاهزة (Sticky / Handwritten / Mind Map)، تصميمها ثابت
  ولا يمكن للمستخدم تعديل الألوان أو الخطوط أو الأماكن — يُدخل المحتوى فقط.
- نموذج إدخال يُبنى تلقائيًا من بيانات القالب (`templates.js`)، لذلك إضافة قالب
  جديد أو تخصص جديد لا يحتاج كتابة واجهة جديدة، فقط إضافة بيانات في ملفات `data/`.
- معاينة حيّة للتصميم أثناء الكتابة.
- حفظ الملاحظات في `localStorage` وعرضها في صفحة "ملاحظاتي" مع إمكانية الفتح والحذف.
- تحميل الملاحظة كصورة PNG عالية الجودة (بدون واجهة الموقع، التصميم فقط).
- تصميم متجاوب بالكامل (Mobile / Tablet / Desktop) وواجهة عربية RTL كاملة.

## ملاحظات للتوسع لاحقًا

- **إضافة قوالب جديدة:** أضف كائنًا جديدًا في `src/data/templates.js` بنفس البنية
  (`fields` بأدوار `title/item/line/central/branch`) — سيظهر تلقائيًا في قائمة
  قوالب التخصص المعني.
- **الانتقال إلى Firebase:** استبدل الدوال داخل `src/utils/storage.js` فقط
  (`getSavedNotes`, `saveNote`, `deleteNote`, `getNoteById`) بمكافئاتها في
  Firestore؛ باقي المشروع لن يحتاج أي تعديل لأنه يتعامل مع هذه الدوال فقط.
- **تصدير PDF:** يمكن إضافته لاحقًا بجانب `downloadNodeAsPng` في
  `src/utils/exportImage.js` دون التأثير على بقية الكود.

> ملاحظة تقنية: تمت كتابة هذا المشروع في بيئة بدون اتصال بالإنترنت، لذلك لم
> يُشغَّل `npm run build` هنا للتحقق النهائي. تم فحص جميع ملفات JavaScript
> العادية (`data/`, `utils/`) بنجاح، ويُنصح بتشغيل `npm install && npm run dev`
> محليًا كخطوة أولى للتأكد من كل شيء يعمل كما هو متوقع.
